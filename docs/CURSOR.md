# 用户指针：格式与用法

> 自定义指针插件（`plugins/core/cursor`）的**用户侧契约**。
> 这份文档是"用户自己加的指针长什么样、放在哪"的**唯一定义处**。

---

## 1. 一句话

**一个用户指针 = 用户指针目录里的一张图片**（PNG / JPG / SVG），外加一条说明
**热点**（图案里"真正指着的那一点"）的清单记录。

---

## 2. 放在哪

| 文件 | 位置 |
| --- | --- |
| 用户指针图片 + 清单 | Windows `%APPDATA%\GoldingCore\cursors\`；其它 `~/.golding/cursors/` |
| 当前选择（§8） | 同一根的 `cursor.ini`：Windows `%APPDATA%\GoldingCore\cursor.ini` |

Windows 上即 `C:\Users\<你>\AppData\Roaming\GoldingCore\`。

**为什么不在插件目录或 exe 旁边**：那两处是**程序**的地盘（升级会覆盖），用户
自己加的东西该跟着用户走，不该被一次升级抹掉。

界面上的入口：设置 → 鼠标指针 → **用户指针…** → 「打开目录」直接开这个文件夹。

---

## 3. 支持什么图片

| 格式 | 说明 |
| --- | --- |
| `.png` | 推荐。带 alpha 的图最好（箭头的边缘不会是一块方）。 |
| `.jpg` / `.jpeg` | 没有 alpha 通道，边缘会有方形底色。 |
| `.svg` | 矢量图，按原尺寸渲染。 |

**按原图 1:1 显示**（不做缩放）。想要别的尺寸，改图本身；内置图案用设置里的
小 / 中 / 大三档。

读不出尺寸（格式不支持 / 文件损坏）的图**不会出现在列表里**，也不会被导入。

---

## 4. 热点（hotspot）

热点 = 图案里**真正指着的那一点**：箭头的笔尖、准星的中心、圆点就是它自己。

- 单位：**图片像素**（相对图片左上角）。
- 默认值：**图片中心**。
- 界面上改：用户指针面板里点「热点」→ 预览图上**点一下** = 把热点定在那儿 →
  立刻写进清单。

热点决定了"指针的哪一点压在鼠标位置下面"，所以箭头类图案一定要调：笔尖不在
热点上，指针就会"偏"。

---

## 5. 清单：`cursors.index`

与图片同目录，**一行一条**，字段用 **TAB** 分隔：

```
文件名 <TAB> hotX <TAB> hotY [<TAB> 显示名]
```

真实例子：

```
# cursors.index —— 用户指针的热点表（每行：文件名 <TAB> hotX <TAB> hotY [<TAB> 显示名]）
pen.png	12	8	我的笔
ring.png	16	16
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 文件名 | 是 | **纯文件名**，不含目录、不许 `..`（清单是用户可编辑的文本，路径穿越必须挡） |
| hotX | 是 | 热点 x（图片像素） |
| hotY | 是 | 热点 y（图片像素） |
| 显示名 | 否 | 空 = 用文件名去扩展名 |

**为什么是 TSV 而不是 JSON**：插件层拿不到 core 的 JSON 解析器（core 是编进
宿主 exe 的静态库，不给插件链接），而 TSV 一行一条、`split` 就能用；它同时是
人能直接打开改的文本——"用户自己加指针"这件事，用户有权自己编辑清单。

**清单只管热点**，文件列表以**目录**为准：

- 目录里有、清单里没有 → 能用（热点取中心）；
- 清单里有、目录里没有 → 那一条直接忽略（文件被删了）。

所以"删一个指针"就是删文件，不必两处同步。

---

## 6. 导入的三条路

| 方式 | 怎么做 | 适合谁 |
| --- | --- | --- |
| 界面导入 | 设置 → 鼠标指针 → 用户指针… → 「导入图片…」→ 选文件 → 在预览上点一下定热点 | 绝大多数人 |
| 手动放置 | 把图片丢进用户指针目录 → 面板里点「刷新」 | 想批量放图的人 |
| 命令行 | `golding_host.exe "--cursor-import=D:/pic/pen.png"` | 脚本 / 批量 / 无界面环境 |

三条路走的是**同一份导入实现**（复制到用户目录 + 写清单 + 热点默认中心），
不是三份各写一遍的代码。

- 导入**不覆盖**同名文件：重名自动加序号（`pen.png` → `pen-2.png`）。
- 导入后**立刻生效**：当前指针切成它。
- 指针的 id = `user:<文件名去扩展名>`（`pen.png` → `user:pen`）。

---

## 7. 程序里怎么用

用户指针**也在样式列表里**（服务 `golding.cursor`，契约 v2），所以别的插件
遍历样式列表时自然就会看见它们：

```cpp
const golding::CursorService* cursor =
    host.Use<golding::CursorService>(golding::kCursorServiceName, 2);
if (cursor != nullptr) {
    // 列出全部图案（内置 + 用户指针）
    for (int i = 0; i < cursor->styleCount(nullptr); ++i) {
        std::printf("%s = %s\n", cursor->styleIdAt(nullptr, i), cursor->styleTitleAt(nullptr, i));
    }
    // 选中一个用户指针
    cursor->setStyle(nullptr, "user:pen");
}
```

**注意**：`styleCount` 会随用户指针目录里的文件变，调用前**重新问一次**，不要
缓存上一次的答案。

另有 `setImage(绝对路径, 宽, 高, hotX, hotY)`：换一张**不在用户目录里**的图
（不登记、不持久化，只是这一次换上去）。

---

## 8. 记住的选择：`cursor.ini`

挑好的指针**不会因为关程序而丢掉**：选中的图案（内置或用户指针）、启用开关、
按下特效、尺寸三档都写进 `cursor.ini`（与 `cursors\` 同一个根），下次启动读回来。

**格式**：一行一对键值，字段用 **TAB** 分隔，`#` 开头是注释：

```
# cursor.ini —— 指针插件自己的偏好（每行：键 <TAB> 值）
style	cross
enabled	1
effects	1
scale	1
```

| 键 | 值 | 作用 |
| --- | --- | --- |
| `style` | 内置图案 id（`arrow` / `ring` / `cross` / `dot` / `spark` / `quill`）或用户指针 id（`user:pen`） | 用哪只指针。缺省 = 出厂默认（`arrow`） |
| `enabled` | `1` / `0` | `1` 用自定义指针，`0` 交回系统指针 |
| `effects` | `1` / `0` | 按下特效（涟漪 / 拖尾） |
| `scale` | `0.5` ~ `3` | 内置图案的尺寸系数（设置里的 小 / 中 / 大 = `0.75` / `1` / `1.4`） |

几条行为：

- **删掉这个文件 = 回到出厂状态**，不会有任何报错。
- 文件里写的用户指针**已经被删了**（图片不在了）→ 退回默认图案，并在日志里说一句。
- 坏行 / 未知键 / 越界值一律跳过、钳住，不猜也不整体失效——这是人能直接改的文本。
- `setImage` 换的临时图**不写进去**（见 §7）。
- `--cursor-demo` 演示模式**不写**这个文件：它一路换图案，写下去就是拿演示覆盖
  用户的真实选择。

---

## 9. 已知边界

- **不支持多状态指针**（hover / pressed 各一张图）。按下反馈是**程序算出来的**
  （形变 + 涟漪），不是另一张图。要加多状态，是把清单格式扩一档的事。
- **不支持动画指针**（多帧序列）。
- **不支持 `.cur` / `.ani`**（Windows 原生光标格式）。它们的热点在文件头里，
  格式本身不难读，但那是"另一种资源类型"，不在 v1 的范围里。
- 用户指针**不跟随内置图案的缩放档**（那三档只作用于程序化图案）。
